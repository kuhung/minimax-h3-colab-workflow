核查日期：2026-11-02。

> 任何“改走 MiniMax API / API 对照 / API 出 2K / API fallback”均作废，不执行；2K、H3-Context-IR、H3-Max 等托管能力不在本仓库路线内。

## 一、核心结论精炼

1. **模型指认**：MiniMax H3（海螺 AI 3.0，2026 年 7 月底发布，8 月初开放开源权重）。非 Hailuo 2.3（闭源 API）。
2. **算力与额度**：Google AI Pro 赠送每月 200 计算单元（Compute Units），非固定小时制。参考费率估算（待首轮 Benchmark 核准）：**L4 约 2.8~4.8 CU/h，A100 约 6.5~11.8 CU/h，具体请以 Colab 右上角「资源」面板实时显示费率为准**。200 CU 约支持 L4 运行 ~40~70 小时，A100 运行 ~16~30 小时，必须开启 Watchdog 与自动销毁防止挂机。
3. **硬件可行性关卡**：
   - **T4（16GB，算力 7.5）**：**不可用**。Int8 ConvRot 算子要求 CUDA Compute Capability ≥ 8.0。硬跑必崩溃或规格极小无实用价值。
   - **L4（24GB，算力 8.9）**：**主力推荐**。显存与性价比最佳，搭配剪枝 int8 变压器 + NVFP4 文本编码器 + CPU 卸载，可稳定出 544p-768p。
   - **A100（40GB/80GB）**：速度最快，适合决赛出片，但额度消耗快，需防止挂机。
4. **模型体量瘦身**：
   - 原始全精度约 123.6GB+，单卡绝对无法装下。
   - 方案采用 Comfy-Org 剪枝量化方案：剪枝 int8 扩散模型（~20.97GB）+ NVFP4 文本编码器（~15.69GB）+ VAE，总计 ~42.5GB。
5. **加速层选型**：
   - 筛选阶段：Turbo LoRA（4-8步）快速验证镜头构图。
   - 决赛阶段：PDD Acc LoRA（8步）稳健生成 768p 终稿。
6. **无脸视频音画策略**：
   - H3 音画同出：在提示词中必须同时描述场景视觉与环境声/音效。
   - 旁白解说：不要赌 H3 原生语音稳定性，建议后期单独配音轨合成；H3 原生音频留作高品质环境背景音（32kHz 立体声）。
